# 📰 Jacobabad Insider

**Jacobabad Insider** is a modern, responsive local news portal built with **HTML5, CSS3, and Vanilla JavaScript**. It provides a professional news publishing platform featuring breaking news, category-based articles, a directory of Jacobabad's notable personalities, and a secure admin dashboard powered by Firebase.

---

## ✨ Features

* 📰 Professional News Portal UI
* 🔥 Auto-scrolling Breaking News Ticker
* 🖼️ Featured News Hero Section
* 📂 Category-based News Pages
* 🔍 Real-time Search
* 👤 Jacobabad Personalities Directory
* 📱 Fully Responsive Design
* 🌙 Dark Mode
* ⚡ Fast & Lightweight Performance
* 📈 SEO Friendly
* 🔐 Secure Admin Login (Firebase Authentication)
* 📝 Add, Edit & Delete News Posts
* 📰 Manage Breaking Headlines
* 👥 Manage Personalities
* ☁️ Cloudinary Image Upload & Hosting
* 🔥 Firebase Firestore Database
* 🚀 Firebase Hosting Ready

## ⚙️ Installation

```bash
git clone https://github.com/yourusername/jacobabad-insider.git
```

---

## 🔐 Configuration

Create your Firebase project and enable:

* Authentication
* Firestore Database
* Hosting

Create a Cloudinary account and configure:

* Cloud Name
* Upload Preset

Update the Firebase and Cloudinary configuration files before running the project.
